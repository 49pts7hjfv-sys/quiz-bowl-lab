# Quiz Bowl Lab

A free study site for a middle-school quiz bowl team: **1,708 topics in 16 content areas** (American and
European History, Literature, Mythology, Religion, Philosophy, Social Science, Fine Arts, Music, Physics,
Chemistry, Biology, Earth Science, Astronomy, Math, Computer Science). The original 215 topics are complete;
the 1,493 topics from the coach's expanded list show as "coming soon" until their pages are written and
reviewed. Every finished topic has a short briefing, hand-picked videos and a kid-friendly reading link
(new topics get their videos in a later pass),
15 original practice tossups with power marks, a clue breakdown from giveaway to power, a "buzzer trap",
and its rank on QBReader's Middle School + Easy High School frequency list.

**Live site:** https://49pts7hjfv-sys.github.io/quiz-bowl-lab/

## How it works
- `index.html` holds the app and a small index of every topic; each topic's full content lives in
  `content/<area>-<nn>.<hash>.json` and is loaded only when a page needs it. GitHub Pages serves both.
- Both are generated by `build.py` from the topic files in `topics/` and the topic list in
  `data/manifest.json`. Don't edit `index.html` or `content/` by hand; edit the sources and rebuild.
- New topics (beyond the original 215) go live only when their id is added to `data/release.json`,
  after they pass `validate.py` and an independent fact review. Topic files being written are never
  picked up by accident.
- Each student's progress is saved in their own browser; nothing is collected. To move progress to
  another device or web address: **My Stats → Copy my backup code**, then **Restore** on the other one.

## Making a change
1. Edit `topics/<id>.json` (content) or `app/` (site code).
2. `python3 validate.py --cross` → must end with `Errors: 0`.
3. `python3 build.py` → rewrites `index.html` and `content/` (never run with `--anki` unless Anki cards are wanted).
4. Commit and push both. The live site updates a minute or two later.

## Folder guide
| Path | What's there |
| --- | --- |
| `topics/` | One file per topic: briefing, tossups, clues, answer lines, videos, frequency rank |
| `data/manifest.json` | All 1,708 topics, 16 areas, and 13 anonymous team study lists (built by `tools/extend_manifest.py` from the coach's spreadsheet using the rules in `tools/curation.py`) |
| `data/release.json` | New topics cleared for the live site |
| `content/` | Built topic content, loaded on demand (generated) |
| `app/` | The site's code (plain JavaScript and CSS) |
| `tools/` | Answer-checker tests, video checker/merger, frequency-list matcher, manifest builder |
| `research/` | QBReader frequency lists (`research/freq/`) and earlier video research |
| `docs/` | Build log and the briefs used to research videos and review content |
| `TOPIC_SPEC.md`, `APP_SPEC.md` | How topics are written and how the app behaves |

## Privacy
No student names appear anywhere in the site or this repository. The coach's assignment spreadsheet
(which has students' names) is deliberately kept out of it; `data/manifest.json` was generated from it
once, with names removed.
