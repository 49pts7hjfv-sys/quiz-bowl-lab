# Quiz Bowl Lab

A free study site for a middle-school quiz bowl team: **215 topics in 11 content areas** (American and
European History, Literature, Mythology, Religion, Philosophy, Social Science, Fine Arts, Physics, Biology,
Earth Science). Every topic has a short briefing, hand-picked videos and a kid-friendly reading link,
15 original practice tossups with power marks, a clue breakdown from giveaway to power, a "buzzer trap",
and its rank on QBReader's Middle School + Easy High School frequency list.

**Live site:** https://49pts7hjfv-sys.github.io/quiz-bowl-lab/

## How it works
- `index.html` is the whole site in one self-contained file. GitHub Pages serves it as-is.
- It is generated by `build.py` from the topic files in `topics/` and the topic list in
  `data/manifest.json`. Don't edit `index.html` by hand; edit the sources and rebuild.
- Each student's progress is saved in their own browser; nothing is collected. To move progress to
  another device or web address: **My Stats → Copy my backup code**, then **Restore** on the other one.

## Making a change
1. Edit `topics/<id>.json` (content) or `app/` (site code).
2. `python3 validate.py --cross` → must end with `Errors: 0`.
3. `python3 build.py` → rewrites `index.html` (never run with `--anki` unless Anki cards are wanted).
4. Commit and push. The live site updates a minute or two later.

## Folder guide
| Path | What's there |
| --- | --- |
| `topics/` | One file per topic: briefing, tossups, clues, answer lines, videos, frequency rank |
| `data/manifest.json` | The 215 topics, 11 areas, and 12 anonymous team study lists |
| `app/` | The site's code (plain JavaScript and CSS) |
| `tools/` | Answer-checker tests, video checker/merger, frequency-list matcher, manifest builder |
| `research/` | QBReader frequency lists (`research/freq/`) and earlier video research |
| `docs/` | Build log and the briefs used to research videos and review content |
| `TOPIC_SPEC.md`, `APP_SPEC.md` | How topics are written and how the app behaves |

## Privacy
No student names appear anywhere in the site or this repository. The coach's assignment spreadsheet
(which has students' names) is deliberately kept out of it; `data/manifest.json` was generated from it
once, with names removed.
